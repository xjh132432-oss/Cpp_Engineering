# Day 06：CMake 入门

## 一、今日学习目标

- 理解为什么需要 CMake：
  项目文件增加后，使用手动 `g++` 命令管理编译和链接会越来越复杂。

- 理解 CMake 和编译器的关系：
  CMake 负责管理构建过程，`g++/clang++` 负责实际编译。

- 掌握 `CMakeLists.txt`：
  使用配置文件描述项目、源文件、头文件目录和 C++ 标准。

- 掌握 `cmake ..`：
  根据 `CMakeLists.txt` 配置并生成构建文件。

- 掌握 `cmake --build .`：
  调用底层构建工具完成项目编译和链接。

- 完成第一个 CMake 多文件工程：
  将 Day 05 项目改造成 CMake 管理的工程。
