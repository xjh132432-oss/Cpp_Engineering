# Day 04：C++ 编译与链接

## 一、今日学习目标

- 理解 C++ 从源码到可执行文件的过程：
  `.cpp → 编译 → .o → 链接 → 可执行文件`

- 理解编译和链接的区别：
  '-o' 编译负责将 `.cpp` 转换为 `.o`；链接负责将多个 `.o` 组合成可执行文件。

- 理解 `.o` 目标文件：
  `.o` 是源码编译后的目标文件，处于编译和链接之间。

- 掌握 `g++ -c`：
  `-c` 表示只编译，不进行链接。

- 理解 `-I` 头文件搜索路径：
  `-Iinclude` 告诉编译器到 `include/` 目录中搜索头文件。

- 完成多文件工程编译：
  将多个 `.cpp` 分别编译成 `.o`，再链接成最终的可执行文件。
